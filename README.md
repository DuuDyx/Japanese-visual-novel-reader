JPVNREADER 
A Java-based tool designed to capture and process text from Japanese visual novels, with the goal of assisting Japanese language reading and translation.
🚧 Project Status
This project is currently under development.

The initial stage focuses on implementing screen capture functionality using Java's Robot and BufferedImage APIs. Future stages will explore OCR, text processing, and translation features.

🎯 Goal
The goal of JPVNReader is to create a lightweight tool that can help users read Japanese text directly from visual novels without interrupting their gameplay experience.
